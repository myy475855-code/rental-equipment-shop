# Rental Shop Management System

Run:
1. python -m venv venv
2. Activate the virtual environment
3. pip install -r requirements.txt
4. python app.py
5. Open http://127.0.0.1:5000

Updated features:
- Multi-product rentals in one invoice
- Different duration per product
- Combined total price per day
- Per-product rental charges
- Customer-agreed deposit of any amount
- Damage/loss charges only at return
- Deposit deduction/refund
- Per-product late fees
- Invoice hidden until Open Invoice
- Printable/downloadable invoice
- Exactly 4 main navigation pages

- Settings modal (no fifth main page)
- Change currency symbol globally, including Arabic currency symbols
- Custom currency symbol support
- Light/Dark theme selection

- Restored old-style left sidebar navigation with active page highlighting and responsive mobile menu

- Restored classic first-version invoice/receipt presentation: invoice details are shown only after clicking Open Invoice / Receipt.
